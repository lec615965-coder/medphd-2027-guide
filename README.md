# 2027 医学博士申请信息站

这是一个无登录、无订阅、无访客数据收集的公开信息查询站。页面只展示带原始链接的官方招生信息；院校主页和导师主页仅作来源入口。

## 内容维护

- data/sources.json：30 所院校的公开来源入口。
- data/notices.json：带官方链接的招生通知和自动发现的官方来源变化提示。
- data/monitor.json：最近检查状态与信息政策。
- scripts/build-static.mjs：将数据复制到静态发布目录。

GitHub Pages 镜像使用定时工作流扫描已登记的官方来源；检测到来源页面变化时自动更新公开数据并重新发布。抓取失败、验证码或来源受限时只更新监测状态，不删除既有公开内容。
